三条路，任选一条。

## A. 本地发布（最快，2 分钟）

在仓库根目录跑：

```powershell
cd D:\code\computerconlex
npm publish --access public
```

如果要令牌，就在 npm 网站现建一个：

1. 打开 <https://www.npmjs.com/settings/~/tokens>
2. **Generate New Token → Granular Access Token**
   - Name：`lens-publish`
   - Expiration：7 days（够用了）
   - **Packages and scopes → Permissions：`Read and write`**
   - **Packages：选 `Only select packages and scopes` → 搜 `dsh-lens-computer-control` 并勾上**
   - 勾上 **Bypass two-factor authentication (2FA)**（这步是关键，否则每次都要输 OTP）
3. 复制出来的 `npm_...` 写进仓库根的 `.npmrc.t2`（这个文件在 `.gitignore` 里）：

```
registry=https://registry.npmjs.org/
//registry.npmjs.org/:_authToken=npm_你的新token
```

4. 再跑 `npm publish --access public`

> 忘了勾 Bypass 2FA 会报 `EOTP`，这时改用 `npm publish --access public --otp=123456`（123456 换成验证器里的码）。

## B. GitHub Actions（一次配置，以后打标签就发）

仓库里已经带了 `.github/workflows/publish.yml`（推 `v*` 标签触发，带 `--provenance`，并会先跑 `npm test`）。

1. npm 网站 → 包页面 → **Settings → Trusted Publishing**，填：
   - Publisher：GitHub Actions
   - Repository：`xxccdl/LensComputerControl`
   - Workflow：`publish.yml`
2. 或者不走 OIDC，改在 GitHub 仓库 **Settings → Secrets → Actions** 加一个 `NPM_TOKEN`（权限同 A）
3. 然后：

```powershell
git tag -a v0.10.0 -m "0.10.0"
git push origin v0.10.0
```
