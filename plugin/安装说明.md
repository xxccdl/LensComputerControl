# 安装说明

Lens 电脑控制 —— 给 AI 装上「看屏幕 + 动鼠标键盘」的能力。
**零第三方依赖**：引擎是随包分发的原生 exe，不需要装 Python / Node 包 / 任何运行时。

---

## 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 2004 及以上 / Windows 11 |
| 运行时 | .NET Framework 4.6+（Win10 自带，无需另装） |
| DSH | 支持本地插件安装的版本 |

---

## 安装步骤

### 1. 解压

把 zip 解压到任意位置，得到一个 `lens-computer-control` 文件夹。
建议放在固定位置，例如 `D:\plugins\lens-computer-control`，**装完别删**（DSH 是链接引用的）。

### 2. 在 DSH 里安装

打开 DSH 的**插件管理**，选择**安装本地插件**，选中刚才那个 `lens-computer-control` 文件夹。

装好后 DSH 会在工具列表里多出 9 个 `computer_*` 工具。

### 3. 重启 DSH

**必须重启一次**：界面层的视觉反馈（四周渐变蓝边 + 顶部胶囊）只有重启后才会加载。

### 4. 验证

随便让 AI 做一件事，比如问它「看一下我现在开了哪些窗口」。
正常情况下：

- AI 能列出一串窗口
- 屏幕四周出现渐变蓝边，顶部出现胶囊：`● Lens AI 正在操作你的电脑`

## 它会做什么

| 工具 | 作用 |
|---|---|
| `computer_windows` | 列出窗口 |
| `computer_focus` | 激活窗口 / 从系统托盘唤出 |
| `computer_scan` | 扫描出可点击候选表 |
| `computer_act` | 点击 / 输入 / 按键 / 拖动 |
| `computer_scroll` | 滚动 |
| `computer_verify` | 核验动作是否生效 |
| `computer_grid` | 坐标网格 |
| `computer_vision` | 纯视觉递归定位（截图切格） |
| `computer_run` | 一次执行多步脚本 |

## 常见问题

**杀毒软件报警？**
引擎 `bin\lens.exe`、`bin\lenshud.exe` 是随包分发的自编译程序（源码在 `native/` 里，全部可查）。
行为上它就是一个自动化工具：读屏、模拟点击键盘——和按键精灵、AutoHotkey 同类，被启发式误报是常见的。
如果被拦截，请把安装目录加入白名单。源码全在包里，可以自己编译核对。

**托盘里的程序唤不出来？**
先用 `computer_focus {window:"微信"}`，它会自动还原隐藏窗口并告诉你 `restoredFromTray:true`。
**不要重新启动那个程序**——会开第二个实例。

**蓝边/胶囊没出现？**
1. 确认重启过 DSH
2. 检查 `%TEMP%\lens-hud\` 目录是否存在（有 `state.txt`、`pid.txt` 说明 HUD 起过）
3. 蓝边和胶囊**对截屏不可见**，所以用截图工具是拍不到的——这是设计，不是 bug

**想关掉视觉反馈？**
`bin\lens.exe hud --action stop`

**想卸载？**
在 DSH 插件管理里移除；然后删掉解压出来的文件夹。

## 已知限制

- **仅 Windows**（大量 Win32 API）
- 托盘**图标**点击未实现：如果某个程序进托盘时把窗口销毁了（而不是隐藏），`focus` 唤不出来
- OCR 会认错字（老师→老丝、取消→取肖），`find=text` 请用短关键词
- 游戏内全屏独占（DirectX 独占模式）抓不到画面，需要切无边框窗口
